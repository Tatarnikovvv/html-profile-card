# Учебная страница-визитка

Небольшой адаптивный сайт, созданный для практики HTML и CSS.

## Что внутри

- семантическая структура HTML;
- стилизация с помощью CSS;
- адаптация карточки для мобильных экранов;
- аккуратная типографика и цветовые переменные.

## Как посмотреть

Откройте файл `index.html` в браузере. Проект не требует установки зависимостей.

## Идеи для следующих улучшений

- заменить текст на информацию о себе;
- добавить ссылки на свои проекты;
- сделать переключатель светлой и тёмной темы;
- добавить отдельную страницу с учебными работами.
